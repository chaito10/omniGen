# CLI Reference

## Global Options

| Flag | Description |
|---|---|
| `-v, --verbose` | Enable verbose logging |
| `--offline` | Operate in offline mode (no downloads) |
| `--dry-run` | Show what would be done without executing |
| `-c, --config <FILE>` | Path to configuration file |
| `-V, --version` | Print version |
| `-h, --help` | Print help |

## Subcommands

| Command | Description |
|---|---|
| `run` | Execute a YAML pipeline workflow |
| `chat` | Start an interactive chat session |
| `image` | Generate or transform an image |
| `video` | Generate or transform a video |
| `audio` | Transcribe audio from a file |
| `models` | List, download, or update models |
| `doctor` | Run system diagnostics |
| `benchmark` | Run performance benchmarks |

See [Commands](commands.md) for detailed command documentation.

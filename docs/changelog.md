# Changelog

### Added

- Initial release candidate
- CLI with all commands: run, chat, image, video, audio, models, doctor, benchmark
- Qwen3 text generation (GGUF)
- FLUX.1 Schnell image generation (SafeTensors)
- LTX Video Distilled video generation (GGUF)
- Whisper Large v3 Turbo audio transcription (SafeTensors)
- YAML pipeline engine with DAG execution
- Automatic Vulkan detection with CPU fallback
- Download manager with resume, retry, and checksum verification
- Tensor caching system
- Memory management with auto-unload
- Parallel task scheduling
- Plugin architecture for extensibility
- MkDocs documentation
- GitHub Pages deployment
- Release automation
